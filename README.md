# Light of the Lost — play page

- `index.html` — the page: logo bar + game window (Full screen / New tab buttons)
- `game/` — put the game here: Version 1's `index.html` + `art-1.js`, `art-2.js`, `art-3.js` (or the repo's `dist/index.html` as `game/index.html`). Replaces the placeholder.

Put it online: drag this folder onto https://app.netlify.com/drop, then share the link with the people you want.
The page is marked noindex so search engines won't list it. Anyone with the link can still play.
Test locally: `python3 -m http.server` in this folder → http://localhost:8000
